## 実測と残る品質課題

buggyの失敗はSAVE10で小計1007に対する期待907/実際906、SAVE20で小計1003に対する期待803/実際802です。割引額の切り捨てを四捨五入へ変えた既知のfixture不具合と一致します。生成テストはtest.eachで実行され、修復でアサーションを成功へ変えていません。

correctとbuggyは別々に計画・生成したため、同じ生成テストを両方へ実行した比較ではありません。各1完了試行であり、安定性や任意の不具合の検出率を示しません。以前の失敗した実行も履歴に残しています。

残る課題は、端数条件を曖昧としながらクーポンテストでは具体的期待値を使う不整合、buggyのクーポンなし条件が既存証拠のみで未検証に残る点です。これらは後続の品質改善として扱い、全条件が検証済みとは表示しません。任意のソース中の秘密検出、完全なOS隔離、実通信の全経路や型チェックも保証していません。
