# ADR 0004: 製品のモデル接続を公式Codex CLIへ委譲する

状態: 採用。ADR整理日: 2026-10-30。既存の公式CLI採用判断を記録する。

## 背景

直接API接続と独自の資格情報処理を減らし、利用者のChatGPT契約でplan/runを実行する必要がある。公式ツールでも、対象コードへの操作権限をそのまま渡すことはできない。

## 決定

Codex CLIを使い、認証・通信・資格情報更新を公式実装へ委譲する。利用者の契約と必要な権限制御を理由に選定し、旧直接API接続と試作Claude接続、自動切替は保持しない。

Latchは入力の許可・固定、生成結果の検証、隔離テスト実行、要件と証拠の対応づけを担う。モデル用CLIは空の一時cwdで起動し、明示入力をstdinへ渡す。公式CLIの対応版と制約を検査し、不一致では推論前に停止する。CLIのログインを送信許可の代わりにはしない。

## 検討した代替案

- 直接APIとキー管理を維持する: 自前の認証・通信の保守が増えるため採らない。
- Claude Codeを継続する: 利用者のChatGPT Plus契約に合わせてCodexへ置き換える。
- 複数CLIや未知の版に自動切替する: 権限と契約の前提を固定できないため採らない。

## 影響

初回対応はCodex CLI 0.163.0、Linux/WSL 2、ChatGPT Plus/Pro、管理設定等のない環境に限定する。汎用的なプロバイダー互換性より検証可能な境界を優先する。CLIの版・契約・モデル提供条件の変更時には再評価する。固定応答の合格と実モデル品質を区別し、完全なOS隔離や任意の不具合検出を保証しない。
