## 中断時と再開時

短い作業はIssue/PRに記録し、複雑な作業だけこのような計画を置きます。Issueは目的・受け入れ条件・関連先、計画は判断と次の操作、実施記録は証拠に役割を分け、同じ進捗一覧を複製しません。

引き継ぎには次を残してください。

```text
目的・Issue:
branch・開始commit・現在commit:
未コミットの変更と保持が必要な人の変更:
完了したこと・残作業:
決定・理由・仮定:
実行した検証と結果・未実施:
PR・対象SHAのCI:
停止理由・次の操作:
```

再開する人は、Issueと計画を読んで `git status --short`、branch・SHA、差分を確認し、環境チェックを行います。以前の成功結果を現在の変更へ流用せず、必要な検証を選びます。再開試行では前の会話を渡さず、欠けた情報・追加質問・再調査・誤操作を記録してください。
